# Описание программы 

Структура данных

A — m×n с коэффициентами ограничений.

b — m-вектор.

c — n-вектор целевой функции.

В фазе 2 расширяем A ← [A | I_m], c ← [c | 0_m].

База/небаза: списки индексов basis и nbasis (типы list[int]).

B_inv — обратная к базисной матрице B = A[:, basis]. Храним и обновляем явно.

Допуск eps = 1e-9

Ничьи разрешаю с помощью правила Блэнда (выбираю минимальный индекс из минимальных элементов) для выхода и входа.
